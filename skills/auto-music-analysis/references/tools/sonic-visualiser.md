# Sonic Visualiser

Status: official capabilities reviewed 2026-11-06; no installed application or review session is claimed. Candidate interface for [result review](../tasks/review.md), disputed [chords](../tasks/chords.md), and [meter transitions](../tasks/meter.md).

Use an available compatible installation to inspect the source with waveform/spectrogram and imported time annotations. Overlay beat/downbeat events and chord labels, loop suspect passages, and retain corrected annotations plus review notes. [Chordino](chordino.md) is a plugin, not built into every installation. [Sonic Annotator](sonic-annotator.md) is the separate batch host.

Record what was actually played or inspected and who made corrections. A visible waveform, opened session, or algorithm agreement does not count as auditory validation. If playback/review is unavailable, report it and leave the disputed label provisional. Follow [setup](../tasks/setup.md) if new software is needed.

Source: [official project](https://www.sonicvisualiser.org/).
