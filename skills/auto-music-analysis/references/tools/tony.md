# Tony

Status: documented candidate, not installed or executed in this project. Tony is an interactive tool for pitch and note annotation of monophonic audio, particularly solo voice.

Use it when reviewing a [vocal transcription](../tasks/notes.md): inspect voicing, octave jumps, slides, repeated notes, and note boundaries against the audio. Prefer an isolated vocal stem when available. It does not replace mixture separation or automatically establish the full song's meter.

Check the actual installed version's supported imports/exports before promising round trips. Preserve original-file timing when transferring corrections back to the structured note events. An opened view is not listening validation; record which passages were actually reviewed.

Source: [official Tony page](https://www.sonicvisualiser.org/tony/).
