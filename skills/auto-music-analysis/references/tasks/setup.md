# Set up an analysis backend

Inspect available executables, Python environments, packages, and local checkpoints before installing anything. Read the selected tool's own reference for platform constraints and automatic downloads. Do not install every documented backend.

Before downloading deep learning weights or downloading/installing heavyweight tools, explain purpose, source, expected transfer/storage size, environment changes, hardware needs, and runtime impact. State unknowns explicitly and obtain explicit consent. This includes weights bundled with packages and first-use automatic downloads. Reuse previously approved tools and weights without asking again when no new download or material change is involved.

For ordinary numerical dependencies, inspect the resolver's footprint and obtain any required setup consent before changing the environment. Keep incompatible tool stacks in separate environments; do not assume the basic DSP interpreter can host every backend.

Before uploading audio or starting paid API jobs, confirm provider, data sent, known retention conditions, and cost/quota impact unless already authorized. Users configure credentials locally or through secure input. Never expose keys in logs, reports, chat, or skill files. Public module documentation is not account access or an executable workflow ID.

Record the selected version, checkpoint, cache location, approved scope, and actual runtime. Documentation-only review is not a successful integration. Return to the relevant [task in SKILL.md](../../SKILL.md) after setup.
