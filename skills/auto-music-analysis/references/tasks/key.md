# Analyze tonality

Use the [local DSP helper](../tools/local-dsp.md) for major/minor profile candidates. Preserve the leading alternatives and correlations; these values are not probabilities. A leading relative-major/minor match is not a confirmed tonic.

For contrasting sections or suspected modulation, compare section-local features and [chord evidence](chords.md). Do not infer a mode from a major/minor lookup or a modulation solely from a changed window maximum. Inspect characteristic pitches and cadences when the available evidence permits.

Report tonal regions in original-file seconds, supported tonic/mode candidates, and uncertainty. Global key output from [Music AI](../tools/music-ai.md) does not establish a local key-change map. Use [review](review.md) before describing a specific mode or confirmed modulation.
